# 已知限制与后续任务

**版本**：v2 ｜ **日期**：2026-10-28

> 本文只记录**实际状态**。凡未实测的功能，一律标注"未验证"。
>
> **项目定位**：美股每日简报生成器——产出每日一张简报长图与 Markdown 文字稿，
> 不包含、也不计划包含任何平台的自动发布功能。

---

## 一、必须首先知道的三个限制

### 1. 项目定位边界：只生成，不发布

- 本项目的交付物是 `data/<date>/images/cover.png`（单张长图）与 `content/report.md`（文字稿）。
- **不实现**任何社交平台的自动发布、登录态管理、验证码处理。
- 历史版本中的发布适配器代码（`publishing/`）保留但默认不启用，仅用于流程测试。

### 2. LLM 生成：百炼（qwen3.8-flash）已实测，其他 provider 未实测

- **已实测**：`LLM_PROVIDER=dashscope` + `DASHSCOPE_API_KEY` 走通完整生成链路，
  产出中文文案通过数字/来源/合规全部校验（`generator=openai_compatible`）。
- **未实测**：Anthropic provider（本机无 key）。
- **已知行为**：模型默认开启思考链，一次完整复盘约 100–120s，容易触发超时；
  建议 `LLM_EXTRA_BODY_JSON={"chat_template_kwargs": {"enable_thinking": false}}`，实测降至 30–40s。
- **已知模型差异**：会输出 `pre-market`、`事实` 这类枚举同义写法（已归一化），
  也会输出 emoji 与 Markdown 标记（图片渲染前已剥离，见 `image_renderer/sanitize.py`）。

### 3. ~~GitHub Actions 工作流未在真实仓库触发过~~（已验收）

- 已真实运行成功（含定时触发与手动触发），产物为单图 + 文字稿。
- `schedule` 存在延迟，已在逻辑层规避（目标日按"最近已收盘交易日"解析）。

## 二、数据源层面的限制

| 限制 | 影响 | 说明 |
| --- | --- | --- |
| Yahoo chart 为非公开接口 | 可能限流/变更/被阻断 | 无 SLA；已做成可插拔 provider，失败即标记缺失 |
| `finance.yahoo.com/news/rssindex` 已 404 | stock-report 等项目的默认源失效 | 本项目已禁用该源 |
| Reuters Agency RSS 404 | 无法使用 | 未纳入 |
| Stooq CSV 404 | 无法作为备选 | 未纳入 |
| Finnhub 免费档不支持 `^GSPC/^IXIC/^DJI` | 免费 key 无法取原始指数 | provider 会明确报"不支持"而非偷偷用 ETF |
| Alpha Vantage provider 未实现 | 无法使用 | 无 key 无法验证，故不提供不可靠实现 |
| 交易日历仅覆盖 2025–2027 | 2028 年起会抛错 | 需更新 `market_data/calendar.py` |
| SEC EDGAR 频率限制 10 次/秒 | 高并发可能被限 | 当前按 ticker 串行，未触及 |
| RSS 内容版权 | 不能全文转载 | 仅引用标题/摘要并保留原链接 |
| Google News RSS 链接为跳转链接 | 部分链接需二次跳转 | 保留原样，不做解析（避免脆弱逻辑） |

## 三、功能层面的限制

| 限制 | 说明 | 后续方案 |
| --- | --- | --- |
| 仅支持盘后复盘 | `pre_open` 枚举预留，调用即 `NotImplementedError` | 实现盘前模式（需覆盖"上一交易日收盘 + 盘前异动"） |
| 无英文→中文翻译 | 规则兜底保留英文标题并加中文类别前缀 | 接入 LLM 后自动获得中文标题；规则模式不保证翻译质量 |
| 审核为 CLI + Markdown | 无 Web 界面、无多用户权限 | 可选做轻量 Web（FastAPI + 单页） |
| 无数据库（默认） | 文件 + JSONL | 已提供 `SqliteTaskStore` 与迁移命令 |
| 图片为纯 Pillow 绘制 | 无图表库、无 K 线 | 如需走势图，手绘折线或引入专门轻量绘图 |
| 未做多账号 | 单账号配置 | 引入账号维度到 `data/<account>/<date>/` |
| 无指标监控 | 仅日志与 artifact | 接入 Prometheus / 邮件 / 企业微信通知 |
| 无速率限制器 | 依赖 provider 自身限流 | 引入令牌桶（若 ticker 数量增大） |
| 交易日历硬编码 | 仅 2025–2027 | 后续从 NYSE 官方日历拉取 |
| 内容指纹不含正文 | 指纹 = 日期 + 新闻 URL + 行情数字 | 若需"正文变化也判重"，把正文哈希并入指纹 |

## 四、安全与合规层面的已知边界

- 合规校验覆盖收益承诺、虚假紧迫感、指令式建议、确定性预测、伪造来源五类；

- 本项目不处理个人信息；不含用户画像或追踪。
