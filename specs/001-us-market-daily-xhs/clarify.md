# Clarify：需求歧义识别与处置

**日期**：2026-10-27
**原则**：非关键歧义采用安全、简单、可维护的默认值并记录假设；仅关键且无法合理推断的才向用户提问。

---

## 已识别歧义与处置（共 10 项，全部采用默认值，无需提问）

### Q1 默认使用哪个 LLM Provider？
- **歧义**：需求只说"可替换的 LLM Provider 接口，支持环境变量配置"，未指定厂商。
- **处置**：实现 `LLMProvider` 协议 + 三个实现：
  1. `OpenAICompatibleProvider`（覆盖 OpenAI / DeepSeek / OpenRouter / 通义 / Moonshot / Groq 等 OpenAI 兼容端点）—— 环境变量 `LLM_PROVIDER=openai_compatible`、`LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`；
  2. `AnthropicProvider` —— `LLM_PROVIDER=anthropic`；
  3. `RuleBasedProvider`（无 key 兜底，只复用已核实数字，不推测）。
- **理由**：OpenAI 兼容端点覆盖面最广；无 key 时必须可跑（需求：不得因可选外部服务不可用而放弃项目）。

### Q2 "3–5 条重要新闻"是硬约束还是建议？
- **歧义**：未说明不足 3 条时如何处理。
- **处置**：取 3–5 条；不足 3 条时标记 `low_confidence=true`，仍生成但**强制要求人工复核**（`review` 状态附带警示），不静默补数量。

### Q3 图片数量 5–7 张如何确定？
- **歧义**：固定还是随内容长度变化。
- **处置**：按内容动态决定：封面 1 张 + 概览 1 + 要闻 1–3 + 异动 1 + 财报/宏观 1 + 次日关注 1 + 风险来源 1，裁剪到 5–7 张区间；配置文件可覆盖 `min_pages` / `max_pages`。

### Q4 图片渲染技术选哪个？
- **歧义**：需求列出 Pillow / SVG / HTML-CSS 转图三种。
- **处置**：**Pillow 单一技术**（见 ADR-005）。理由：依赖最少、CI 友好、中文字体与换行可控；图表用矩形手绘即可，无需图表库。

### Q5 存储用文件还是数据库？
- **歧义**：需求说"数据库或文件存储迁移策略"。
- **处置**：默认 `FileTaskStore`（JSONL + 每日目录，原子写入 + 文件锁），同时提供 `SqliteTaskStore` 与 `migrate` 命令，满足"迁移策略"要求。

### Q6 审核界面用 CLI、Markdown 还是 Web？
- **歧义**：需求说"第一版优先轻量方案"。
- **处置**：**CLI + Markdown 审核文件**（`data/<date>/REVIEW.md`），不做 Web。理由：需求明确"不必过早开发复杂后台"。

### Q7 定时任务的时区和运行时间？
- **歧义**：未指定。
- **处置**：默认 cron `30 22 * * 1-5`（UTC 22:30），对应美东夏令时 18:30 / 冬令时 17:30，即盘后；`workflow_dispatch` 支持 `run_date` 覆盖。目标交易日由 `scheduler` 解析为"最近已收盘交易日"，不直接取触发日。

### Q8 "定时发布"是指平台定时发布还是系统定时运行？
- **歧义**：需求 F 说"支持定时发布任务"，但又说 cron 不保证精确。
- **处置**：**系统定时运行**（GitHub Actions），发布动作在运行后**重新校验**当前时间是否进入允许发布窗口；不允许时置 `scheduled` 等待下次运行。绝不把触发时间当作平台发布时间。

### Q9 真实发布何时算"已验证"？
- **歧义**：需求既要求"经过验证的小红书发布能力"，又要求"不得假定开源项目能绕过平台限制"。
- **处置**：定义明确验收门槛（三条同时满足才标记为已实现）：
  1. 具备合法授权（官方开放平台权限，或用户自有账号的明确授权）；
  2. 目标平台接口/页面结构在当前版本可用且已实测；
  3. 至少一次完整的真实发布（含图片上传）成功并留下可核对的 `result.json`。
  未满足前，文档与 `result.json` 一律标注 `simulated=true` / `verified=false`。

### Q10 用户自定义股票列表与主题如何配置？
- **歧义**：未指定形式。
- **处置**：`config/default.yaml` 提供 `watchlist.tickers`、`watchlist.topics`、`news.feeds`、`news.lookback_hours`；CLI 支持 `--tickers AAPL,TSLA` 覆盖；环境变量支持 `USMARKET_TICKERS` 覆盖。三者优先级：CLI > 环境变量 > 配置文件。

## 需要用户确认的关键项（当前无阻塞，已按默认值实现）

以下两项有业务影响，但已有安全默认值，故不阻塞开发。若需调整请告知：

1. **发布窗口**：默认任何时间允许 mock 发布；真实发布（未来启用）默认仅允许美东 08:00–23:00。
2. **账号名称与品牌色**：默认 `美股日报` + 深蓝/橙配色，通过配置文件可改。
